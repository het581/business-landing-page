# NEXORA — AI Automation Agency

A portfolio-grade responsive landing page built with vanilla HTML, CSS, and JavaScript.

## Run locally

No build step is required.

1. Open the `NEXORA-AI-AGENCY` folder.
2. Open `index.html` in a modern browser.
3. For the best development experience, use VS Code with a local server such as Live Server.

## Structure

- `index.html` — page markup and content
- `css/style.css` — responsive styling and animations
- `js/script.js` — navigation, FAQ accordion, scroll reveal, and counters
- `assets/` — reserved for future images/icons

## Notes

- Pricing, metrics, case studies, and testimonials are demonstration content for a portfolio project.
- The contact CTA uses a demo `.example` email address.
- Google Fonts are loaded remotely; the site otherwise needs no external API.
